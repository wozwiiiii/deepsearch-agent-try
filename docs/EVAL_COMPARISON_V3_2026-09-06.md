# 评测对比报告：v2 vs v3（2026-09-06）

> v3 = P1 早停防护（最终回答守卫）+ 限流指数退避上线后的全量复测。
> 环境事故如实记录：MySQL（Docker）在 routing/multi 批期间停止，相关用例已标污染；multi 批在 DB 恢复后重跑。
> 原则：提升与回退如实并列，污染用例不计入结论分母。

## TL;DR

- **总分 36/45（80.0%，v2）→ 40/45（88.9%，v3）**；剔除污染用例后 **35/40（87.5%）→ 40/41（97.6%）**。
- 三轮曲线：基线 30/45（66.7%）→ v2 36/45（80.0%）→ **v3 40/45（88.9%）**。
- **守卫实战数据：过渡语早停 2 次触发、2 次全部救回**（sql-05、route-01）；同时暴露第二个盲区——空输出早停（n=2，已列新 P1）。
- **指数退避实战数据：5 次 429 退避重试全部成功**（sql-10/18 各 3 次、multi-07 前 2 次），v2 时代同场景报废 2 条。
- 本轮唯一非污染 FAIL：sql-19（模型把"替诺福韦"转述为"替诺福酯"，一字之差，字符级生成噪声）。

## 守卫与退避的实战验证（本轮核心目的）

### 最终回答守卫（P1 早停防护）
| 运行 | 现象 | 结果 |
|------|------|------|
| sql-05 | 早停签名出现（"……请稍"），日志记录守卫捕获 | 强制续跑 → PASS 1.0（tokens 33,275≈普通两倍，符合续跑预期） |
| route-01 | 早停签名出现（DB 故障过渡语），守卫捕获 | 强制续跑 → PASS 1.0（tokens 24,881 两轮） |

对照历史：过渡语早停家族在基线/v2 共 5 次、全部报废；v3 中 2 次出现、**0 次漏网**。

### 新暴露的守卫盲区（P1 → 新待办）
**空输出早停**：route-02、multi-07（不同类别、不同轮次，签名一致：result 为空、零工具、~8.2K tokens、errors 为空）。根因：模型最终消息 content 为空时 `final_reply=None`，`is_pure_transition_reply` 对空文本放行，守卫不触发。n=2 已不能归因噪声，**修复方向：回合结束时最终回答为空且本轮无工具调用 → 同样触发守卫续跑**。v3 报告中这两条已标记污染（`empty_output_early_stop`），不计入结论。

### 限流指数退避
5 次 429 全部在 60s→120s→240s 退避后重试成功（v2 固定 70s×3 时代同场景报废 2 条）。限流用例后 30s 冷却正常执行。

## 污染用例清单（v3 共 4 条，均已留证）

| 用例 | 类型 | 依据 |
|------|------|------|
| route-02 | empty_output_early_stop | 守卫盲区（n=2），人工标记 |
| route-04 | db_connection_down | MySQL 容器停止，模型自述连接失败 + 事后 10061 直连验证 |
| web-09 | external_search_down | Tavily 代理 ProxyError（与 v2 同源） |
| multi-07 | empty_output_early_stop | 同 route-02（n=2） |

**环境事故说明**：MySQL 跑在 docker compose 中，Docker Desktop 隔夜关闭导致 routing/multi 批期间 DB 不可用。multi 首跑 2/7 数据作废，DB 恢复后重跑得 6/7。route-06 恰在 DB 故障窗口内但仅靠 list_sql_tables+网络搜索通过，未标污染（如实说明）。教训：跨夜/长时评测前需确认依赖服务存活。

## 逐条翻转明细

### 转为 PASS（相对 v2，11 条净变化）
sql-12/13/14/18/20/21（+6，v2 时代 429 报废的 sql-14/18 本次在退避保护下正常完成）、web-01（0.8→1.0）、web-03（0.8→1.0）、multi-06（0.73→0.87）等；routing/web/multi 各自有分数提升的 PASS 用例（如 multi-04 0.67→0.93、multi-05 0.93→1.0）。

### 转为 FAIL / 波动（如实报告）
| 用例 | v2 → v3 | 定性 |
|------|---------|------|
| sql-19 | PASS(1.0) → FAIL(0) | 模型把"替诺福韦"转述为"替诺福酯"（品牌名韦瑞德、单价 520 全对）。DB 真值已核实。字符级生成噪声，判 FAIL 成立 |
| route-02 | PASS(1.0) → FAIL(0)* | 空输出早停（守卫盲区 n=2），污染 |
| multi-07 | PASS(0.87) → FAIL(0.2)* | 同上，污染 |
| route-04 | FAIL → FAIL* | 双方都 FAIL：v2 模型贴 Markdown 不调工具；v3 DB 挂掉。均未达标但原因不同 |

## 结论

1. **P1 早停防护达到设计目标**：过渡语早停 0 漏网；但暴露空输出盲区（n=2），列入下一优先级修复（判据扩展：空最终回答 + 无工具调用 → 触发守卫）。
2. **指数退避达到设计目标**：429 重试零报废。
3. v3 剔污染通过率 **97.6%**（40/41）——距离满分仅剩 sql-19 一条字符噪声型 FAIL。
4. 下一批待办优先级：① P1 空输出守卫扩展；② QA 记录的 P2 清理（429 子串匹配收窄、守卫短语表边界）；③ P1 会话级 token 预算与 api_key 兼容入口移除；④ P0-2 任务出进程（4–6 天，项目部署架构唯一缺口）。
